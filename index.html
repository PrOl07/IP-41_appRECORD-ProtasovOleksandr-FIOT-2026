Опис предметного середовища

Предметна область

Предметною областю розроблюваного WEB-застосунку є настільний помічник майстра рольової гри Dungeons & Dragons (D&D). Застосунок призначений для спрощення підготовки та проведення ігрових сесій, а також для швидкого доступу майстра до необхідної інформації під час гри. Основним користувачем системи є Dungeon Master (DM), або майстер гри. Під час проведення сесії майстру необхідно одночасно контролювати перебіг бою, характеристики персонажів, параметри супротивників, порядок ходів, результати кидків кубиків та інші ігрові правила. Тому основною ідеєю WEB-застосунку є об'єднання найбільш потрібних інструментів в одному інтерфейсі. Головна сторінка застосунку виконує роль інформаційної панелі майстра. На ній розміщуються короткі підказки та нагадування щодо правил D&D, які можуть бути потрібні під час гри. Наприклад, це інформація про модифікатори характеристик, основні характеристики персонажа, порядок проведення бою, правила ініціативи та інші часто використовувані ігрові відомості. Окрім сторінки з підказками, застосунок передбачає окремі розділи для роботи з листами персонажів, бестіарієм, бойовим трекером та калькулятором кидків кубиків.

Бізнес-логіка

Основна бізнес-логіка застосунку полягає у швидкому доступі майстра до необхідних ігрових інструментів та інформації. Типовий сценарій роботи користувача може виглядати наступним чином:

  • Майстер відкриває WEB-застосунок.
  • На головній сторінці переглядає необхідні підказки та нагадування щодо правил гри.
  • За необхідності переходить до потрібного розділу за допомогою навігаційної кнопки.
  • Якщо потрібно отримати інформацію про персонажа, відкриває Character Sheets.
  • Якщо під час гри необхідно отримати характеристики супротивника, майстер відкриває Bestiary.
  • Під час бою використовується Battle Tracker для контролю порядку ходів.
  • Для виконання кидка використовується Dice Calculator.
  • Після завершення необхідної операції користувач може повернутися на головну сторінку або перейти до іншого інструмента.

    • Функціональні вимоги

    1. Система повинна відображати головну сторінку з підказками та нагадуваннями щодо правил D&D.
    2. Система повинна забезпечувати навігацію між основними розділами застосунку.
    3. Система повинна дозволяти відкривати та переглядати листи персонажів.
    4. Система повинна забезпечувати перегляд інформації про монстрів у бестіарії.
    5. Система повинна дозволяти використовувати бойовий трекер.
    6. Система повинна дозволяти виконувати кидки ігрових кубиків за допомогою калькулятора.
    7. Система повинна забезпечувати зрозуміле відображення інформації.
    8. Система повинна дозволяти користувачу повертатися до головної сторінки та переходити між розділами без повторного завантаження всієї інформації.
    9. Інтерфейс повинен забезпечувати швидкий доступ до найбільш часто використовуваних функцій під час ігрової сесії.

    Нефункціональні вимоги

    • Основна сторінка вебзастосунку повинна повністю завантажуватися не більше ніж за 3 секунди за стабільного інтернет-з'єднання зі швидкістю не менше 10 Мбіт/с.
    • Перехід між розділами застосунку без завантаження нової сторінки повинен виконуватися не більше ніж за 1 секунду після натискання користувачем відповідної кнопки.
    • Відображення інформації про персонажа, монстра або результату кидка кубика повинно відбуватися не більше ніж за 2 секунди після виконання відповідної дії.
    • Вебзастосунок повинен підтримувати одночасну роботу щонайменше 20 користувачів без збільшення часу відгуку основних операцій більше ніж на 30 %.

    2. Надійність

    • Вебзастосунок повинен забезпечувати коректну роботу основних функцій протягом безперервного сеансу використання тривалістю не менше 2 годин.
    • У разі помилки окремої операції застосунок не повинен припиняти роботу всього інтерфейсу; користувач повинен мати можливість продовжити роботу не пізніше ніж через 5 секунд після виникнення помилки.
    • Після перезавантаження сторінки застосунок повинен відновлювати доступ до основних розділів не більше ніж за 3 секунди.
    • Доступність вебзастосунку повинна становити не менше 99 % протягом календарного місяця для розгорнутої версії.

    3. Зручність використання

    • Новий користувач повинен мати можливість перейти від головної сторінки до будь-якого основного розділу (Character Sheets, Bestiary, Battle Tracker, Dice Calculator) не більше ніж за 2 натискання.
    • Назви основних розділів та кнопок повинні бути зрозумілими без звернення до додаткової документації.
    • Основні елементи навігації повинні залишатися доступними на всіх основних сторінках застосунку.
    • Виконання основної операції, наприклад відкриття аркуша персонажа або запуску калькулятора кубиків, повинно вимагати не більше 3 послідовних дій користувача.

    4. Адаптивність

    • Інтерфейс повинен коректно відображатися на екранах із шириною від 320 до 1920 px.
    • При зміні ширини вікна браузера з 320 до 1920 px жоден основний елемент інтерфейсу не повинен виходити за межі області перегляду.
    • На екранах шириною до 768 px елементи навігації повинні автоматично переходити в адаптоване розташування без горизонтального прокручування основного вмісту.

    5. Сумісність

    • Вебзастосунок повинен коректно працювати в актуальних версіях Google Chrome, Microsoft Edge та Mozilla Firefox.
    • Основні функції повинні залишатися працездатними в браузерах, що підтримують сучасні стандарти HTML5, CSS3 та JavaScript ES6+.
    • Відображення основних сторінок не повинно містити критичних помилок при використанні операційних систем Windows 10/11, macOS та Android.

    6. Безпека

    • Вебзастосунок повинен використовувати HTTPS для передачі даних у розгорнутій версії.
    • Дані, які вводить користувач у форми, повинні перевірятися перед обробкою протягом кожного надсилання форми.
    • Паролі, якщо в майбутньому буде реалізована авторизація, не повинні зберігатися у відкритому вигляді.
    • Користувач без відповідних прав не повинен мати доступу до функцій або даних, призначених для іншого рівня доступу.

    Тема

    Каскадні таблиці стилів. Селектори тегу, класу, ідентифікатора. Стильове оформлення текстових елементів в HTML-документах.

    Мета

    Придбати практичні навички роботи з CSS-селекторами, ідентифікаторами, списками, властивостями кольору та фону, зовнішніми й внутрішніми відступами, плаваючими елементами та оформленням тексту.

    Теоретичні відомості

    CSS (Cascading Style Sheets) — мова таблиць стилів, яка використовується для оформлення HTML-документів. За допомогою CSS можна змінювати кольори, шрифти, відступи, межі, розташування елементів та їхню поведінку під час взаємодії з користувачем.

    У цій роботі приклади реалізовано на тематиці WEB-застосунку для майстра настільної рольової гри Dungeons & Dragons.

    Селектори тегу

    Селектор тегу застосовується до всіх HTML-елементів відповідного типу. Наприклад, правило для h3 оформлює заголовки третього рівня.

    HTML-код

    <h3>Поради майстру гри</h3>
<p>Перевірте ініціативу перед початком бою.</p>

    CSS-код

    h3 {
    color: #654321;
    font-family: Georgia, serif;
    border-bottom: 2px solid #c6a15b;
    padding-bottom: 6px;
}

    Селектори класів

    Селектор класу починається з крапки та застосовується до всіх елементів, яким призначено відповідний атрибут class. Один клас можна використовувати для кількох елементів.

    HTML-код

    <div class="character-card">
    <h3>Персонаж гравця</h3>
    <p>Клас: Паладин</p>
    <p>Рівень: 3</p>
</div>

    CSS-код

    .character-card {
    background-color: #f8f0df;
    color: #3d3023;
    border: 1px solid #b89b65;
    border-radius: 12px;
    padding: 18px;
    margin: 12px 0;
    box-shadow: 0 3px 8px #00000018;
}

.character-card h3 {
    margin-top: 0;
}

    Селектори ідентифікаторів

    Селектор ідентифікатора починається зі знака #. Він застосовується до елемента з відповідним унікальним значенням атрибута id.

    HTML-код

    <div id="main-tips">
    <h3>Нагадування майстру</h3>
    <p>Перед боєм визначте порядок ініціативи.</p>
</div>

    CSS-код

    #main-tips {
    background-color: #e7edf8;
    color: #203654;
    border-left: 5px solid #426a9b;
    padding: 18px;
    margin: 15px 0;
    border-radius: 6px;
}

#main-tips h3 {
    margin-top: 0;
}

    Інші селектори

    1. Дочірній селектор

    Символ > вибирає елементи, які є безпосередніми дочірніми елементами іншого елемента. 

    .spell-list > li {
    color: #654321;
    margin-bottom: 6px;
}

    2. Сусідній селектор

    Символ + вибирає елемент, який безпосередньо розташований після вказаного сусіднього елемента на тому самому рівні вкладеності. 

    .section-heading + p {
    font-style: italic;
    color: #555;
}

    3. Селектор атрибута

    Селектор атрибута дає змогу вибрати елементи за значенням їхнього атрибута. 

    input[type="number"] {
    border: 2px solid #9a7b42;
    padding: 8px;
    border-radius: 5px;
}

    4. Універсальний селектор

    Символ * вибирає всі елементи документа або всі елементи в межах заданого контейнера. 

    * {
    box-sizing: border-box;
}

    CSS: Шрифти, текст, таблиці, фон, контур, списки, CSS просунутий

    1. Шрифти, текст і колір

    Властивості шрифту визначають гарнітуру, розмір і насиченість тексту. Властивості тексту керують вирівнюванням, міжрядковим інтервалом і декоруванням. 

    .styled-text {
    font-family: Georgia, serif;
    font-size: 18px;
    font-weight: bold;
    line-height: 1.7;
    text-align: left;
    text-decoration: none;
    color: #46351f;
    text-shadow: 1px 1px 1px #00000015;
}
    Майстер гри керує пригодою, а гравці створюють її історію.

    2. Фон, контури та відступи

    Властивості фону задають колір або зображення. Межі та контури допомагають візуально виділяти важливі елементи. Внутрішній відступ задається через padding, зовнішній — через margin. 

    .notice-box {
    background: linear-gradient(135deg, #fff8e8, #ead8b5);
    border: 1px solid #b89b65;
    outline: 2px solid #eee1c7;
    border-radius: 10px;
    padding: 16px;
    margin: 12px 4px;
}
    Порада: підготуйте статистику монстрів до початку бойової сцени.

    3. Оформлення таблиць

    Для таблиць можна використовувати об'єднання меж, відступи комірок, фон заголовків і зміну кольору рядків під час наведення курсора. 

    .styled-table {
    width: 100%;
    border-collapse: collapse;
}

.styled-table th,
.styled-table td {
    border: 1px solid #a99a7c;
    padding: 10px;
    text-align: left;
}

.styled-table th {
    background-color: #e8dcc2;
}

.styled-table tbody tr:hover {
    background-color: #f5eddd;
}

    5. Просунутий CSS

    Псевдоклас :hover застосовує стиль під час наведення курсора. Властивість transition робить зміну стилю плавною, а box-shadow додає тінь. Flexbox допомагає розташовувати елементи в рядок або колонку. 

    .feature-list {
    display: flex;
    flex-wrap: wrap;
    gap: 12px;
}

.feature-item {
    flex: 1 1 150px;
    padding: 14px;
    background-color: #f3ead8;
    border-radius: 8px;
    transition: transform 0.2s, box-shadow 0.2s;
}

.feature-item:hover {
    transform: translateY(-3px);
    box-shadow: 0 5px 12px #00000020;
}
